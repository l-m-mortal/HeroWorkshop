# Hero Workshop: передача для локальной работы

Документ поддерживается на каждом шаге. Цель: любая новая сессия (в том числе локальная,
с доступом к папке игры и запуску Warcraft III 1.31.1 на macOS) может продолжить работу,
не восстанавливая контекст из чата.

## Окружение

* Игра: `Warcraft III/` (macOS, 1.31.1). Карта: `Maps/Downloads/Dota_Radiant_Terrain_Fix_v4.w3x`
  (DotA 6.85ne14). Эталон: `Dota Mod Project/Sources/Packs/DOTA 2 mod/DOTA-HQv5_RePack.part01/Maps/Download/DotA v6.77b.w3x`
  (DotA 6.77b с HQ-модом для 1.26a).
* Репозиторий: `Dota Mod Project/Tools/HeroWorkshop`, ветка `claude/optimistic-gauss-alg516`.
  Скрипты запускаются из этой папки: `python3 map_fix.py <fix> [--apply]`, `python3 workshop.py ...`, `zsh *.sh`.
* Файлы мода лежат рядом с игрой: `WC3DotaHQTest/A/...`, `WC3Dota2Test/...`, `WC3WardotaTest/...`.
  **Важно:** loose-файлы на диске имеют приоритет над файлами в карте. Модель, лежащая в
  `WC3WardotaTest\...`, нельзя починить, положив копию в карту: правится файл на диске
  (`model-events --into root`), либо в карте меняется путь модели.
* Сохранение состояния: `state/<карта>/state.json` (не в git): иконки, масштабы, списки
  перенесённых декораций (`doodads_added`, `custom_doodads_added`), удалённые размещения
  (`removed_placements`), сдвиги частей сборки (`model_lift`).
* Дамп карты без моделей для анализа: `python3 map_fix.py dump` -> `.work/<карта>/dump.zip`.

## Сделано и работает в игре

* Иконки героев/способностей/предметов, масштабы (workshop.py + SwiftUI).
* Модели лавок: `map_fix.py shops --apply` (боковая = Merchant, потайная = пустая HQ-модель ShopKeeper).
* Кулдауны над панелью команд и над инвентарём: `cooldown-numbers --font 0.022 --apply`
  (Инвокер припаркован: вызванные заклинания исключены).
* Окраска юнитов снята: `untint --apply`; Войд после Time Walk белый: `script-tints --apply`.
* Магазин-окно (чистый JASS, `shop_jass.py`, `shop-ui --apply`, `-shop` в чате): отрисовка,
  покупка через штатную продажу лавки, потайные предметы не покупаются.
* Уплотнение карты: `compact --apply`.
* Декорации 6.77b перенесены (`doodads`, `custom-doodads`, `doodads-z`, `remove`, `overlaps`).
* Сборка AshenRock7 (стены и лестницы обеих баз в одной модели): части поднимаются внутри
  модели командой `model-lift` (`zsh stairs.sh N <группа|DSxx>`), значения абсолютные.

## Открытые проблемы (по приоритету)

1. **Нумерация частей сборки AshenRock7.** Расчётные мировые координаты частей (`stairs.sh`
   комментарий) не совпадают с тем, что видит пользователь: при подъёме частей 3,4,11,12,13,20,30
   на 200 поднялись три лестницы в нижнем лесу Radiant, стена у фонтана (части 0,1 на 150)
   не двигалась. Диагностика: `zsh labels.sh` ставит текстовые метки DS00..DS12 в игре в
   расчётных точках (`part-labels`); по скриншотам сопоставить метки с реальными частями и
   переписать группы в `stairs.sh`. `zsh labels.sh off` убирает метки.
2. **Звук дальней атаки (Снайпер `Usyl`, Дроу `Nbrn`).** Причина: в моделях из наборов
   Wardota/Dota2 нет звуковых событий. Донор Снайпера (`Build/DotaHQ/.../Rifleman.mdx`):
   `SNDxKRIF` на кадре ~23% анимации Attack. Донор Дроу (BansheeRanger.mdx): звуковых
   событий атаки нет вовсе (звук через weapsd1 в данных). Команда:
   `model-events --path 'WC3WardotaTest\Units\Human\Rifleman\Rifleman.mdx' --events 'SNDxKRIF@370' --into root --apply`
   (после `--into root` результат ещё не проверен). Коды событий -> звуки: `animlookups.slk`
   (`Build/DotaHQ/Inputs/NativeSoundInfo/`). Припарковано по решению пользователя.
3. **Магазин.** Ожидается версия с фильтром по команде (только лавки своей базы, без боковых),
   отладкой покупки составных предметов (сейчас покупается только рецепт), кнопкой SHOP на
   панели команд (абсолютная привязка), панелью ниже табло. Панель правее 0.8 обрезается
   при родителе GAME_UI; `--parent world` даёт полную ширину.
4. **Потайные лавки.** Юнит `uC74` теперь невидим (HQ ShopKeeper.mdx = пустая модель), а
   шатёр торговца нужно ставить отдельно. В 6.77b рядом с лавками декораций нет (см. probe),
   значит шатёр давала другая модель торговца; модель шатра Radiant с коврами в HQ-папке не
   найдена (искать в `Dota Mod Project/Sources/Packs/...` по `secretshop`, `ShopKeeper`).
   Лавка Dire: `zsh dire_shop.sh` ставит навес из Obstacle2 без частей ямы Рошана.
5. **Деревья Radiant.** Аудит: типы те же, что в 6.77b; HQ-ёлки берутся с диска. Команда
   `trees` (вложить HQ-модели `Doodads/Terrain/AshenTree/*` и текстуры
   `ReplaceableTextures/AshenvaleTree/*` в карту) не написана.
6. **Столбы с цепями у фонтана Dire**: неизвестно, были ли до правок (пользователь не ответил).
7. Магазин v6, лестницы Dire, лавки: после закрытия пунктов выше.

## Полезные команды

```zsh
python3 map_fix.py list                      # все исправления
python3 map_fix.py probe --at=X,Y,R          # декорации вокруг точки здесь и в 6.77b
zsh fix_scene.sh                             # вся сцена разом, повторяемо
zsh stairs.sh N [all|radiant|dire|rad-wall|...|DS03]
zsh walls.sh N [radiant|dire|тип]
zsh labels.sh [off]
```
