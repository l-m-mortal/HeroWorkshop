# Промпт для локальной сессии Claude (запускать на Mac, в папке с Warcraft III и проектом)

Скопируйте текст ниже целиком в новую сессию Claude Code, запущенную на вашем Mac.
Перед запуском положите рядом два файла из репозитория HeroWorkshop:
`docs/map_external_refs.txt`, `docs/map_other_missing_refs.txt` и скрипт `library_scan.py`.

---

Ты помогаешь подготовить инвентарь ассетов для проекта Hero Workshop: редактора карты DotA
(Warcraft III 1.31) на macOS, который заменяет иконки, модели, портреты, HUD и текстуры ландшафта.
Другая сессия Claude, работающая в облаке без доступа к моему диску, уже разобрала карту
`Dota_Radiant_Terrain_Fix_v4.w3x` и знает, какие файлы карта ищет снаружи. Твоя задача: изучить
мои локальные папки и собрать для той сессии полное, машиночитаемое описание того, что у меня есть
и где это лежит. Ничего не изменяй и не удаляй в моих папках. Все результаты складывай в новую папку
`HeroWorkshop_inventory/` в текущем каталоге.

## Что искать

1. Установку Warcraft III 1.31 (внутри есть `Warcraft III.app` или `Warcraft III.exe`, папка `Maps`).
   Рядом с ней ожидаются папки модов: `WC3DotaHQTest`, `WC3Dota2Test`, `WC3WardotaTest`.
2. Установку Warcraft III 1.26a, если есть, и папку мода Dota HQ V5 для неё.
3. Папку `Dota Mod Project` (внутри `Tools`, `Workspaces/Dota2`, `Icon Audit`, `HeroWorkshop`).
4. Все папки с иконками Dota 2 в PNG (современные иконки героев, способностей, предметов).
5. Любые другие папки с ассетами Warcraft III: `.mdx`, `.mdl`, `.blp`, `.tga`, `.fdf`, `.toc`, `.slk`,
   `.w3x`, `war3mapSkin.txt`, HUD-текстуры (`UI\Console\...`, `UI\Widgets\...`), текстуры ландшафта
   (`TerrainArt\...`, `ReplaceableTextures\Cliff\...`).

Начни с `~/`, `/Applications`, `~/Documents`, `~/Downloads`, `~/Desktop`, внешних дисков в `/Volumes`.
Ищи по именам папок и по расширениям (`find`/`mdfind`). Если найдёшь несколько копий одного и того же,
опиши все и укажи, какая новее и полнее.

## Что выдать

Создай в `HeroWorkshop_inventory/`:

1. `LOCATIONS.md`: абсолютные пути ко всему, что нашёл из списка выше, с одной строкой описания
   каждого. Отдельно ответь: включён ли в Warcraft III 1.31 режим локальных файлов
   (`Allow Local Files`, для Mac это `defaults read com.blizzard.warcraftiii` или
   `~/Library/Preferences`, проверь и напиши, что нашёл), и какая версия игры установлена.
2. `TREE.md`: дерево каждой найденной корневой папки. Для папок с числом файлов до 300 выводи полный
   список файлов. Для больших папок выводи структуру подпапок до глубины 4 и для каждой подпапки
   число файлов, суммарный размер и раскладку по расширениям. Используй `tree` или `find` с `du`.
3. `manifest.zip`: запусти скрипт `library_scan.py` (он лежит рядом, требует `python3` и Pillow:
   `python3 -m venv .venv && .venv/bin/pip install Pillow`) на всех найденных папках ассетов:
   `.venv/bin/python3 library_scan.py "<путь1>" "<путь2>" ... --out HeroWorkshop_inventory/manifest`.
   Он создаст `manifest/manifest.json`, PNG-превью иконок и HUD и упакует всё в `manifest.zip`.
   Если превью получаются больше 300 МБ, повтори с `--max-thumb-mb 250`.
4. `REFERENCES.md`: возьми файл `map_external_refs.txt`. В нём пути вида
   `WC3DotaHQTest\A\Units\Orc\HeroFarseer\HeroFarSeer` без расширения: в игре это `.mdx` для моделей и
   `.blp` или `.tga` для картинок. Для каждого пути проверь, существует ли такой файл относительно
   папки Warcraft III (регистр букв и обратные слэши игнорируй, `\` это разделитель папок). Выдай
   таблицу: путь из карты, найденный абсолютный путь или «НЕ НАЙДЕН», размер. В конце сводка: сколько
   найдено, сколько нет, и список отсутствующих сгруппированный по первым двум папкам.
   Затем то же самое для `map_other_missing_refs.txt`, но там ищи только внутри папок модов и
   `Dota Mod Project`, стандартные файлы Warcraft искать не нужно.
5. `ICONS_DOTA2.md`: для папок с иконками Dota 2 опиши схему именования файлов (примеры для героя,
   способности, предмета), размеры картинок и формат, чтобы можно было автоматически сопоставлять их
   с rawcode способностей из карты.
6. `HUD.md`: перечисли все найденные HUD-файлы (`UI\Console`, `UI\Widgets`, `UI\Cursor`,
   `UI\Feedback`, `UI\MiniMap`, `.fdf`, `.toc`, `war3mapSkin.txt`) с путями, размерами картинок и
   тем, из какого набора они (Dota HQ V5, Wardota, SelectedMix и так далее).

В конце сожми папку `HeroWorkshop_inventory/` в `HeroWorkshop_inventory.zip` и напиши мне, какие файлы
внутри и их размер. Если что-то не нашёл, так и напиши, не придумывай пути.
